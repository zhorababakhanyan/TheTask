# TheTask 🚀

TheTask is an iOS application built with Swift and SwiftUI using the MVVM architecture. It connects to an API to fetch users via a GET request and register users via a POST request. 🔄

## Configuration Options ⚙️

- **Token Management:** Tokens are automatically generated and managed by the app. If a token expires, the app automatically requests a new one and stores it in `UserDefaults`. No manual configuration is needed by the user. 🔑

## Dependencies 📦

This project uses no external libraries or dependencies and is fully native. 🛠️

## Requirements 📱

- **iOS version:** 18.2 or higher 📲
- **Xcode version:** 16.2 💻
- **Device:** Portrait mode only 📸

## Building the Application 🛠️

1. Clone the repository:
   https://github.com/zhorababakhanyan/TheTask

2. Open the `.xcodeproj` file in Xcode. 🔓

3. Select the appropriate scheme and build/run the app. ▶️

## Troubleshooting ⚠️

- There are no known issues. If you encounter any problems, please ensure your environment meets the above requirements. ✅
